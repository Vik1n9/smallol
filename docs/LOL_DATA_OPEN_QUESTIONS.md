## 條款與法律（待查證）

- **Riot 的同人創作政策**：Riot 對非商業的同人專案有公開政策，可能允許使用部分遊戲素材（例如英雄頭像），但要附上規定的免責聲明（俗稱「Legal Jibber Jabber」）。這跟 MLB 完全不能用 logo 不同，要讀原文確認範圍。
- Riot 開發者 API 的使用政策（10/6 另一個 session 讀過 Riftbound 的部分：developer.riotgames.com/policies）。
- 戰隊 logo、選手照片通常屬於戰隊或聯盟，不在同人政策內，預設不用。
- 非公開介面是「被容忍、非正式承諾」，要寫在資料源文件裡。

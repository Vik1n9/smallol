# SmalLoL 最終規格 v1(實作依據)

**單位:** 尺寸為邏輯 px。時間為毫秒或秒,另標。這些是定版值,實作時直接用。驗收時我以逐幀截圖核對,走樣的退回令重做。

---

## 1. 主視圖細條

### 尺寸分檔

| 檔 | 高度判定 | 參考尺寸 | 寬度範圍 | 內容 |
|---|---|---|---|---|
| 點 | < 40 | 220×28 | 180–600 | 單列:`●MVK 12:9 FUR●  14:32` |
| 條 | ≥ 40 | 340×48 | 300–600 | 兩列(下述) |

- 高度固定,只能橫向縮放。檔位以 container query 判定。
- 點與條之間用圖示列的 ⤢ 切換,各檔記住自己的寬度。
- 點檔點擊條身:切回條。
- 背景三段(實底/半透明/全透明)、拖曳與右下縮放沿用 Basesmall。
- 字型沿用 Basesmall 字型堆疊;數字用等寬字。

### 兩列內容(比賽進行中)

```
│ ●MVK 12 : 9 FUR●   14:32   經濟 +2.3k │  列 A:狀態(11px,次要色,各 24 高)
│ 12:31 ▍FUR 拿下巴龍                    │  列 B:log 行(13px)
```

- 列 A 的順序:藍方色點、代碼、殺數、冒號、殺數、代碼、紅方色點,然後比賽時間、經濟差(領先方色)。
- 寬度 < 320 時,列 A 省略經濟差。
- 列 B:行首是該事件的比賽時間(等寬、次要色),接著是 ▍(行動方邊色,中性事件用 `--accent`),再接文字。
- 系列賽比分不放在條上,見第 5 節。

### 靜止與亮起

| 項目 | 規格 |
|---|---|
| 靜止 | 整條 72% 不透明 |
| 事件進來 | 亮到 100%,10 秒內退回 72% |
| 列 B 老化 | 2 分鐘內不透明度線性降到 60% |
| 換字(舊) | 上移 4px、淡出,120ms,ease-in |
| 換字(新) | 從下方 6px 滑入、淡入,200ms,`cubic-bezier(.2,.8,.2,1)` |
| 一般 | 只換字 |
| 重要 | 加行首色點閃一次,600ms |
| 重大 | 加整條邊框單發光暈:1200ms,box-shadow 由「1px 行動方色 90% + 12px 光暈 50%」衰減到 0,不循環 |
| 連推更新 | 只換數字:舊上移 4px 淡出、新下方 4px 淡入,120ms |
| 減少動態偏好 | 一律只做不透明度,120ms |

**換字規則(保留期):**
- 新事件等級 ≥ 現行行 → 立刻取代。
- 新事件等級 < 現行行,且現行行仍在保留期 → 只進歷史,不取代。
- 保留期:重大 30 秒、重要 15 秒、一般 6 秒。

### hover 圖示列

- 滑鼠移上去,**列 A 在 120ms 內交叉淡出,換成圖示列**,離開 300ms 後換回。條本身不改尺寸。
- 圖示列由左到右:`模式標籤「上班 ▾」`、歷史、面板 ▾、資料、暫停通知、⤢、設定。每個圖示 24×24 熱區。
- 「面板 ▾」選單三項:小地圖、本局 BP、選手面板。每項有勾選狀態。
- 「資料」開資料窗,回到上次的頁籤,首次開到賽程。
- 「暫停通知」:點一次暫停卡片與小條 30 分鐘,再點恢復。暫停中,列 A 左端常駐一個靜音小圖示。暫停期間 log 行與歷史照常更新。
- 「設定」開資料窗的 ⚙ 頁籤。

### 點擊行為

| 動作 | 行為 |
|---|---|
| 條身點擊(位移 < 4px) | 展開或收合歷史(第 5 節) |
| 條身按住拖曳(位移 ≥ 4px) | 拖視窗 |
| Esc | 收合歷史 |
| 展開後滑鼠離開 60 秒 | 自動收合 |
| 模式標籤 | 開模式面板(第 3 節) |

## 2. 通知

### 視窗

- 單一視窗,螢幕工作區右下角,邊距 12。
- 寬 316,內容靠右。高度**隨內容伸縮**(0 到 260),無內容時隱藏,沒有空的透明區。
- 不可取得焦點,不搶前景。
- 同螢幕規則沿用 `notifier.ts`:以主視窗所在螢幕為準。

### 兩種項目

| | 卡片 | 小條 |
|---|---|---|
| 尺寸 | 300×56;BP 完成 300×84 | 260×32 |
| 內容 | 第一列標題(13px 粗體)+ 右上時間(等寬 11px);第二列附註(11px 次要色) | 單行(12px):▍ 文字 + 右端時間 |
| 色條 | 左側 3px,行動方邊色;中性事件 `--accent` | 同左 |
| 停留 | 8 秒 | 4 秒(從最後一次更新起算) |
| 滑鼠移上 | 整個堆疊暫停計時 | 同左 |
| 點擊 | 消除該項 | 消除該項 |
| 進場 | 220ms ease-out,y 8→0 + 淡入 | 180ms ease-out,y 8→0 + 淡入 |
| 退場 | 160ms 淡出 | 160ms 淡出並收合高度 |

- **BP 完成卡片(84 高):** 第一列「BP 完成 · {A} 對 {B}」,下面兩列各一隊,格式「{代碼} {五個鎖定英雄}」。英雄用短名(最多 4 字),五個放不下時整列縮到 10px,不省略名字。順序依鎖定順序。
- **水晶被破卡片:** 第二列可放兩個附註,「已連推 3 塔 · 重生 5:00」。
- **所有 DOM 用鍵值增刪節點,不整批重寫 `innerHTML`**,舊卡片不得重播進場動畫。
- 堆疊:最新的在最下,間距 6,既有項目往上移 160ms ease。

### 堆疊上限

- 卡片同時最多 2 張。第 3 張進來時,最舊的卡片提前退場。
- 小條同時最多 3 條。需要第 4 條時,最舊那條與之後溢出的併成「+N 則 ▸」,點了開歷史,停留 4 秒。

### 合併規則

| 規則 | 鍵 | 窗 | 行為 |
|---|---|---|---|
| R1 連推 | (行動方, 塔類)。外塔、內塔、高地塔、主堡塔同屬塔類 | 15 秒 | 在畫面上的同一條小條與 log 行原地更新為「{T} 連推 n 塔 · {最新塔}」;小條停留從最後一次更新重算,**單條最長存活 20 秒**,到了再開一條,計數延續。歷史仍每座塔一列 |
| R2 水晶附註 | — | — | 水晶被破卡片的第二列,若 R1 的連推還在進行,附「已連推 n 塔」 |
| R3 升 6 級 | 事件類型,不分隊伍 | 15 秒 | 併成「升 6 級 · {T} {位置}、{T2} {位置} +n」,最多列兩個名字 |
| R4 第一件傳說裝 | 事件類型,不分隊伍 | **30 秒** | 併成「第一件成裝 · {T} {位置}、{T2} {位置} +n」,最多列兩個名字 |
| R5 同輪 | — | 一次 5 秒輪詢 | 一個標題加最多一個附註(R2 例外) |
| R6 不合併 | — | — | 小龍、預示者、三蟲、單殺與陣亡、BP 逐手、其餘所有事件 |

**全部選手後的調整:** 升 6 維持 15 秒。第一件傳說裝因為十位選手的完成時間分散,一開始就用 30 秒。若第三輪試算在陪看模式下,60 秒視窗小條峰值仍超過 4,**先調窗口**(升 6 → 30 秒、第一件傳說裝 → 45 秒),不縮範圍。

### 安全閥

- 卡片 60 秒內最多 3 張。第 4 張起降為小條,事件本身的設定不變。
- 暫停通知、低調模式生效時,卡片與小條都不發。
- 卡片音效:預設關,第三批提供開關,只給卡片。

## 5. 歷史展開

**尺寸:** 展開後共 340×244:列 A(24)+ 8 列清單(8×24=192)+ 篩選列(28)。清單超過 8 列時內部捲動。

### 展開動畫

- 列 B 原地變成清單第一列,**位置不動**。其餘列由上而下淡入並下滑 6px,160ms ease-out,每列延遲 20ms。
- 篩選列放在**遠離條的一端**。

### 方向

- 條下方空間足夠 → 向下長,清單最新在上。
- 條在螢幕下半部、下方放不下 → 向上長:視窗整體上移 196,條在畫面上的位置不動,清單最新在下(靠近條),篩選列在最上。
- 視窗位置只保存**收合狀態**的位置。

### 列格式(24 高)

- `mm:ss`(等寬 11px、次要色、44 寬)| 側色點 + 代碼(28 寬)| 文字(超長以省略號截斷)。
- 重大列:文字粗體,左側加 2px `--accent` 軌。
- **每局一個分組標題**(20 高,貼頂):「第 {n} 局 · {A} 對 {B}」。系列賽比分只在「顯示比分」開啟時附在標題後。

### 篩選

`全部 | 重要事件(重大+重要)| {A} | {B}`

### 行為

- 連推的各座塔在歷史中各自一列。
- 列中的隊伍代碼點了進**隊伍檔案**,選手 ID 點了進**選手檔案**(開資料窗,第 6 節)。
- 保留最近 5 局。本地存 `<app config>/log-history.json`;服務提供事件端點後,以服務為準補齊(App 晚開也完整)。
- 沒有端點前,歷史只含 App 開著之後的事件,中途啟動只在最上面放一條基準行,不重播舊事件。

## 6. 資料窗與三個選開視窗

### 資料窗

- 340×360,固定尺寸,內容內部捲動。
- 頁籤:**賽程 | 隊伍 | 全場 BP | ⚙**。
- **可取得焦點**(搜尋框需要鍵盤)。其餘選開視窗與通知視窗一律不可取得焦點。
- 開啟:180ms,淡入並由 0.98 放大到 1。
- 賽程與全場 BP 頁籤**沿用現有內容**,只縮進這個窗。不爆雷標記與「顯示比分」開關沿用,且同時管轄勝率。
- 賽程列的隊名點了進隊伍檔案。賽程點進去的先發列表,選手 ID 點了進選手檔案。

### 隊伍頁籤:索引

```
[ 搜尋隊伍、選手…            ]
今日出場       [FUR] [MVK]
我的隊伍       [..]
LCK           [T1 ] [GEN] [HLE] [KT ]
LPL           [BLG] [JDG] [TES] [AL ]
```

- 分組順序:今日出場、我的隊伍、各賽區(組內依種子排序)。
- 代碼格 56×24,四欄,中性色,**不使用戰隊或遊戲公司的標誌與隊色**。
- 搜尋同時比對隊伍(代碼、全名)與選手(ID、本名、母語名),結果分兩段。輸入法組字中不過濾,`compositionend` 後才比對。
- 鍵盤:↑↓ 移動、Enter 進入、Esc 清除搜尋、Backspace 返回。

### 層級轉場

- 進入一層:內容往右推,160ms ease-out。
- 返回:往左,160ms。
- 返回箭頭 ← 加麵包屑,例如「FUR › {P}」。

### 隊伍檔案

- 標題:代碼(16px 粗體)、全名、賽區 · 聯賽、種子標籤、起始階段、晉級路線(11px、最多兩行)。
- 教練列:ID · 職稱 · 國籍。
- 名單:先發五列加替補,22 高。每列「位置 ID 國籍 · 年齡」。國籍一律中文字,不用國旗 emoji。
- 「▸ 本屆 BP」可收合區(常禁常選),預設收合。
- 右上 **☆ 我的隊伍**。

### 選手檔案

- 標題:ID、位置 · 先發/替補。
- 一行簡介。
- 一列:本名 · 母語名(與本名不同才顯示)· 國籍 · 年齡 · 出道年。
- 三格:世界賽冠軍、MSI 冠軍、聯賽冠軍。
- 「世界賽 N 次 · 最近 {年}」,可展開為全部年份。
- 「本屆上場 N 局」。
- 本屆英雄池:前五個,每個「英雄 ×場次」;勝率受不爆雷開關管轄,隱藏時只顯示場次,不留空洞。英雄池標題右側有「顯示勝率」小按鈕,與全域開關同步。
- **沒有「追蹤選手」星號。**

### ⚙ 設定頁

- 通知模式與事件編輯器(四態、分組收合)、即將出現提前量、開賽提醒提前量、里程碑範圍、我的隊伍、不爆雷、背景模式、語言(跟隨系統/繁中/English)、卡片音效(預設關)、還原預設版位。

**錄影**,60fps 螢幕錄影,**逐幀抽出連拍圖**交給我看。我以 16.7ms 一格核對時序:
1. 列 B 換字(一般→重大):舊淡出約 7 格,新滑入約 12 格,光暈約 72 格。
2. 保留期:先送巴龍,10 秒內送單殺,列 B 不被取代;30 秒後送單殺,列 B 改變。
3. 連推:重播 Day 3 的連續倒塔,**只出現一條小條**,計數 1→2→3,列 B 同步,舊卡片沒有重播進場。

5. 小條溢出:快速送 5 個小條事件 → 出現「+N 則 ▸」。
6. 暫停通知:靜音圖示出現,暫停中事件只更新列 B。
7. 模式切換:回饋一行出現 3 秒,不進歷史。
8. **不搶焦點:** 在記事本打字時觸發卡片,打字不中斷,`GetForegroundWindow` 不變。
9. **點擊穿透:** 有 3 條小條時,點小條堆疊上方的透明區域,確認點擊落到底下的視窗。
